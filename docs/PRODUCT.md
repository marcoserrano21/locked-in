# Marco Locked-In — Product

## Thesis

Most habit apps track intent. This one tracks the next block.

One screen. One job. Proof over vibes.

## Who it is for

Marco: Tesla Wed-Sat, Full Sail deadlines, Sun/Mon/Tue build days, controlled Uber, freelance Monday money block, 30-day lock.

## Retention model

1. **Commitment contract** — start date locked; Day X/30 always visible
2. **Identity streaks** — core blocks only; soft targets never inflate the number
3. **Loss aversion** — incomplete core near midnight gets a soft warning
4. **Variable reward** — check seal + day complete moment
5. **Edit friction** — plan changes allowed mid-lock, but logged for Day 30 honesty
6. **Money truth** — Uber $/mi with soft stop at 400 miles and hard ceiling at 500

## Narrative arc

| Phase | Job |
|---|---|
| Day 0 | Commit. No optimizing. |
| Daily | Current block is the only CTA |
| Weekly | Build (Sun-Tue) vs maintenance (Wed-Sat) |
| Day 30 | Review the five questions below with data, not feelings |

## Day 30 review rubric

1. Did Wednesday assignments get submitted the night before, not last minute?
2. Did the apartment stay clean without a Sunday scramble?
3. What did Uber actually net after energy cost, and how many miles did it cost?
4. Did freelance outreach happen every Monday, even when you did not feel like it?
5. Did the once/twice-a-month family call happen, or get skipped?

## Non-goals (this pass)

- Accounts / cloud sync
- Push notifications
- App Store / Play wrap
- Full freelance CRM

## Success

Installable PWA, offline after first load, editable schedule, honest streaks, Uber soft-stop, docs aligned with UI.
